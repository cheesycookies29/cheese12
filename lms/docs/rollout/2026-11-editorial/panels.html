ATLASColophonNo. 7 of 10

ATLAS is written in plain JavaScript and runs on Node.js 22, using only its standard library. No framework and no outside packages: every line is Lancaster's own. Caddy serves it over HTTPS. Records live in one data file with atomic saves; passwords are hashed with scrypt, then encrypted with AES-256-GCM under a key kept apart from the data. Keycloak single sign-on is optional.

Every request passes eight checks
  1. 1
    HTTPS onlyEncrypted, with HSTS for a year
  2. 2
    Address checkOnly the school's own address
  3. 3
    Rate limitsPer person and per network address
  4. 4
    Same-site onlyJSON from ATLAS's own pages
  5. 5
    SessionA random token scripts cannot read
  6. 6

  7. 7
    ScopeCampus, class and family
  8. 8
