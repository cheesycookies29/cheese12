Under the hood · The backend

Simple to run. Built to last.

ATLAS is built like CORE: one Node.js program that uses only Node's own standard library, browser apps with no build step, and all records in one data file. Nothing to license, nothing to keep patched but Node itself.

Browsers & phones

Seven web apps

Plain JavaScript modules and CSS, served as they are: no framework, no bundler.

Optional · Single sign-on

Keycloak (OpenID Connect)

Sign in with the school's account; PKCE and signed tokens checked by the server. The client secret stays in the server's environment.

Security
