# ATLAS rollout: concept art

Concept art for announcing ATLAS, made as a set like *CORE by Lancaster* (the ERP's rollout): eleven 1250-px panels for email and slides, in one PDF and as separate PNGs (2×).

**Newer set:** [`2026-11/`](2026-11/README.md), November 2026: Finance, payroll into Finance, the school calendar, the Settings center, the REX Bookstore e-Reader, CORE and ATLAS, and what ATLAS is built on.

| `p02` | What's inside: Learn, People, Academic: three systems, one sign-in |
| `p03` | **Sibling projects**: CORE runs the company, ATLAS runs the school; CORE's HR & Payroll engine powers ATLAS People; one design language; built the same way |
| `p04` | Learn: from first lesson to final grade |

| `p11` | Roadmap: what is in development |

- `ATLAS_by_Lancaster_RD.pdf`: all panels, one per page.
- `png/`: each panel as a PNG, to place in an email (one image per panel, with alt text) or a deck.
- `panels.html`: the source. Edit the text there and re-render (open it in Chromium and screenshot each `section.panel`, or print to PDF). Fonts come from `public/fonts/`, screenshots from `screens/` (the demo school, renamed *Lancaster Academy*), marks from `assets/`.

To fill in before sending: the launch date and the sign-in address (`p10` says "to be announced", as CORE's did).
